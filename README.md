# All Tools Nexora - Web Edition

Website clone UI + fitur utama dari video tutorial Nexora (Vecto + SVG → Alight XML).

## Fitur
- Dashboard gelap modern mirip Nexora
- Kategori: All / Downloader / Maker / Tools
- **Vecto** : Raster → Vector (upload gambar, setting Style/Detail/Warna, generate SVG, preview, download)
- **SVG → Alight XML** : Upload SVG, pilih engine Maximum Fidelity, convert, preview XML, download/copy
- Integrasi langsung dari Vecto ke SVG2XML
- Responsive mobile-first

## Cara Deploy
1. Upload seluruh isi folder ini ke hosting (Netlify, Vercel, GitHub Pages, atau VPS)
2. Atau buka `index.html` langsung di browser
3. Tidak butuh backend / API key

## Catatan
- Konversi vector menggunakan engine simulasi lokal (demo fidelity tinggi)
- Untuk production vectorize nyata, hubungkan ke service seperti Vectorizer.AI / potrace backend
- XML Alight Motion dihasilkan dalam format kompatibel untuk import
